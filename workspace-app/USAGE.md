# 使用说明（USAGE.md）

## 首次使用

1. 打开网站 → 初始化向导：设置考试日期 / 科目 / 学习程度 / 导入资料（可跳过）；
2. 向导完成后进入**今日工作台**。

## 核心模块

| 模块 | 用法 |
|------|------|
| **今日工作台** | 查看每日任务；点「开始学习」计时；完成后记录结果 |
| **AI 学习助手** | 输入「今天学什么」「分析最近三套真题」「制定今天学习计划」等；未配置密钥时明确显示「演示回复」 |
| **知识中心** | 上传 PDF/DOCX/TXT/MD/图片；真题库按套卷原卷浏览；Reader 内选中文字可存批注；知识图谱随学习自动生成 |
| **成长卡片** | 在 Reader/AI 中将重点存为卡片，进入「沉淀卡片」背诵复习 |
| **设置** | 考试目标、科目、AI 配置、学习方法；**数据管理**可导出/导入 JSON 备份 |

## 数据备份

「设置 → 数据管理 → 导出学习档案」下载 JSON；「导入数据」可恢复（换设备/清理浏览器前建议导出）。

## 真题库说明

- 真题按**整套套卷**展示与阅读（不逐题拆解）；
- 有文本层的套卷支持 AI 讲解 / 题干解析；扫描件可原卷阅读（AI 降级提示）；
- 平台内置 72 套公共课真题的声明与命名规范，PDF 文件需自行放置（见 `public/papers/README.md`）。
