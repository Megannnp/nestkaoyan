# 筑巢考研工作台 — 产品需求文档 (PRD)

## 1. 产品定位

筑巢考研工作台是一个 **AI-native 考研学习操作系统**。它不是传统的学习管理工具，而是 Agent 驱动的学习环境——用户与 AI Agent 协同管理考研全过程。

### 核心哲学

- **AI First, User Confirms**：AI 自动识别、推荐、调整，用户确认后写入
- **7 核 4 层 6 轮**：七核知识图谱 + 四层学习深度 + 六轮复习节奏
- **数据驱动**：所有学习决策基于掌握度、错题率、风险等级

## 2. 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 考研学生 | 使用所有学习功能，查看/修改个人数据 |
| AI Agent | 学习助手 | 自动识别资料、生成任务、更新图谱、建议计划 |

## 3. 核心功能模块

### 3.1 今日工作台 (Dashboard)
- **今日任务**：AI 生成或用户手动创建的学习任务列表
- **计时与记录**：任务开始计时、完成记录、学习时长追踪
- **今日复盘**：每日/周/月复盘，含学习数据统计、AI 总结
- **备用任务机制**：当主任务负荷过大时切换为低负荷备用任务

### 3.2 AI 学习助手 (Agent)
- **对话交互**：自然语言提问（"今天学什么"、"为什么总错这类题"）
- **Agent 工作流**：分析真题 → 更新图谱 → 更新掌握度 → 重排计划 → 生成笔记
- **规则引擎**：基于学习数据的本地规则推荐（暂未接入 LLM）

### 3.3 知识中心 (Knowledge)
- **资源与阅读**：上传资料（PDF/图片），AI 自动识别科目、类型、章节
- **真题库**：真题录入、筛选（科目/七核/结果/关键词）、做题记录
- **知识图谱**：七核 → 分支 → 知识点的三层结构，掌握度追踪

### 3.4 成长卡片 (Cards)
- **间隔重复**：基于掌握度自动计算复习间隔
- **多种卡片类型**：公式卡、概念卡、填空卡、推导卡、条件辨析卡、错题卡
- **多模式学习**：背诵、填空、推导、条件辨析

### 3.5 设置 (Settings)
- **考试目标**：院校、专业、考试日期、每周时间安排
- **科目管理**：增删改科目，配置目标分数、轮次、风险状态
- **AI 配置**：启用/禁用功能、回答详细程度、数据读取权限
- **数据导入导出**：JSON 格式完整数据备份与恢复

## 5. 技术约束

- **Next.js App Router**（当前使用 vinext 兼容层）
- **localStorage** 持久化（后续可迁移至 D1 数据库）
- **无外部 API 依赖**：当前所有 AI 功能由本地规则模拟
- **客户端渲染**：所有页面逻辑在 `"use client"` 组件中
