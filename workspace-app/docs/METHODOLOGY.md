# 学习方法论（METHODOLOGY.md）

> 这套系统不是「打卡 + 记事本」，它内置了一套完整的学习方法：**逆向设计 × 7核 × 4层 × 6轮**。
> 大白话讲清楚「它怎么帮你学」——每一步都有 AI 帮你盯着。

## 一句话

**先看考试要什么，再把整门课按「七核一周扫一遍、四层逐个过关、六轮循环加固」学完，全程用知识图谱和 AI 动态计划盯着。**

---

## 1 · 逆向设计：先看目标，再安排学习

传统学习是「拿到教材从第一章开始」，这套系统反过来：**先看考试要什么，再回头安排学习**。

- **真题和大纲定方向**——告诉你考什么、怎么考
- **教材帮助理解**——把考点讲透
- **教辅拓展深化**——补充练习与延伸

所有材料按「谁服务谁」组织，**优先学真题反复考、分值大的内容**，而不是平均用力。

## 2 · 7 核：一周走一遍全局

从真题中抽出**统领全科的七个核心**，一天攻克一个，一周走完一遍。

- 快速摸清整门课的**骨架**，避免「第一章学了三周、后面没时间」的失衡
- 之后每一轮复习都可以用 7 核作为主线反复加固

> 示例（政治公共课）：马克思主义基本原理 / 毛泽东思想和中国特色社会主义理论体系 / 中国近现代史纲要 / 思想道德与法治 …… 每科都有自己的一套「核」。

## 3 · 4 层：从「知道」到「会用」

每个知识点按**四层递进**学习，四周四层，一层一过关，不赶进度：

| 层 | 目标 | 大白话 |
|---|---|---|
| 1 · 理解 | 看懂是什么 | 知道有这么个概念 |
| 2 · 展开 | 弄清来龙去脉 | 它为什么是这样、和谁有关 |
| 3 · 练习 | 会做基础题 | 能在简单题里用出来 |
| 4 · 综合 | 能用于整卷答题 | 放到整张卷子里也不慌 |

## 4 · 6 轮：循环推进，一轮比一轮快

整门课整体过 **6 轮**，一月一轮是标准节奏：

`打底 → 连线 → 补漏 → 提速 → 真题 → 冲刺`

- 每一轮都在上一轮基础上加快：**前几轮慢而全，后几轮快而准**
- 时间紧也没关系：按剩余天数**倒推轮次**，压缩到能做几轮就做几轮，系统会重新排期

## 5 · 知识图谱 + 学习者模型：学没学会，有数

- 所有知识点被连成一张**「谁依赖谁」的网**：先修知识点没掌握，后续内容学了也容易塌
- 每个知识点都有一张**掌握度快照**：当前掌握度、近期变化、遗忘风险、下次复习时间
- **该复习哪个、哪些可以跳过，系统按你的真实状态算，不靠感觉**

## 6 · 动态计划 + Agent 闭环：AI 每天帮你推理

计划不是排一次就死掉：AI 综合你的目标、知识图谱状态、剩余时间，**推理今天到底该做什么**，每天都给出可执行的任务。

形成 **「计划 → 执行 → 反馈 → 调整」** 闭环：

```
学习前：明确学什么（动态计划）
学习中：随时记录（计时 / 掌握度 / 正确率）
学习后：AI 分析效果并更新状态（复盘 / 图谱更新）
```

## 7 · 适合哪些考试

| 类型 | 适配度 | 说明 |
|---|---|---|
| **成体系、需要背诵的科目**（专业课、政治等） | ✅ 最适合 | 图谱和掌握度模型作用最大 |
| **英语等需要长期积累的科目** | 🟡 部分适合 | 单词、长难句可用 7 核与多轮循环；手感型内容需额外刷题配合 |
| **靠临场手感发挥的题型** | ❌ 不适合 | 系统不擅长替代「大量随机练习」建立的手感 |

## 这套方法论在产品里怎么用（对应功能）

| 方法论 | 产品落地 |
|---|---|
| 逆向设计 | 真题库（72 套公共课）+ 资料导入（PDF/DOCX/TXT/MD/图片）→ AI 自动识别考点 |
| 7 核 | 知识中心 · 知识图谱按「七核」组织；卡片按七核分组 |
| 4 层 / 6 轮 | 今日工作台任务带「轮次 / 层级」标签；计划按轮次重排 |
| 知识图谱 + 学习者模型 | 知识中心掌握度快照、遗忘风险、下次复习时间 |
| 动态计划 + Agent 闭环 | AI 学习助手（真题分析 / 计划生成 / 错因分析 / 对话即执行） |
| 复盘 | 复盘页统计今日完成、掌握度变化，反哺明日计划 |
