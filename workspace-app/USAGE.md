# 使用说明（USAGE.md）

> 大白话版，跟着点就行，30 秒上手。

## 首次使用

1. 打开网站 → 初始化向导：设置**考试日期 / 科目 / 学习程度 / 导入资料**（都可以跳过，后面在「设置」里随时改）
2. 向导完成后进入**今日工作台**——这就是你每天打开的地方

## 每天怎么用（核心闭环）

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| 1. 看任务 | 「今天学什么」已经由 AI / 计划生成好，直接看任务列表 | 今日工作台 |
| 2. 开始学习 | 点「开始学习」计时，完成后记录结果（时长 / 掌握度 / 正确率） | 今日工作台 |
| 3. 有问题问 AI | 「分析最近三套真题」「这道题为什么错」「制定今天学习计划」 | AI 学习助手 |
| 4. 沉淀卡片 | 阅读 / AI 对话里选中重点 → 存成卡片 → 进入「沉淀卡片」背诵 | 知识中心 / AI 助手 |
| 5. 复习复盘 | 打开**复盘**看今日完成情况，决定明天怎么学 | 复盘 |

## 核心模块

| 模块 | 用法 |
|------|------|
| **今日工作台** | 每日任务；点「开始学习」计时；完成后记录结果；打卡热力图 |
| **AI 学习助手** | 输入「今天学什么」「分析最近三套真题」「制定今天学习计划」等；未配置密钥时明确显示「演示回复」 |
| **知识中心** | 上传 PDF/DOCX/TXT/MD/图片；真题库按套卷原卷浏览；Reader 内选中文字可存批注；知识图谱随学习自动生成 |
| **成长卡片** | 在 Reader / AI 中将重点存为卡片，进入「沉淀卡片」背诵复习（间隔重复） |
| **设置** | 考试目标、科目、AI 配置（网关地址 / 模型 / Key）、学习方法；**数据管理**可导出/导入 JSON 备份 |

## 真题库说明

- 真题按**整套套卷**展示与阅读（不逐题拆解）
- 有文本层的套卷支持 AI 讲解 / 题干解析；扫描件可原卷阅读（AI 降级提示）
- 平台内置 72 套公共课真题的声明与命名规范，PDF 文件需自行放置（见 `public/papers/README.md`）

## 数据持久化与备份

- 数据默认**双写**：浏览器 localStorage（秒开离线）+ 本地 SQLite（`data/kaoyan.db`，权威持久化）
- **换浏览器、清缓存、换设备（同一局域网）自动恢复**，无需手动导出导入（含 PDF/DOCX/文本文件与 AI 网关配置）
- 额外备份：随时「设置 → 数据管理 → 导出学习档案」下载 JSON；「导入数据」可恢复
- **访问密码**：本机打开免登录；其他设备（手机/局域网）访问需输入密码（首次安装自动生成，见 `data/password.txt`）

## 手机 / 其他设备访问

同一网络（同一 WiFi）下，浏览器打开 `http://<电脑IP>:3000`，输入访问密码即可（macOS 查 IP：终端运行 `ipconfig getifaddr en0`）。

想公网随时访问（不在家也能用）→ 见 [DEPLOY.md](./DEPLOY.md)。
